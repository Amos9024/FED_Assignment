# Electricity Calculator
The purpose of this project is to create/develop a simple web application to educate end users on the electricity cost of the appliance usage.
# Design Process
The web application is designed to help users to learn how the calculation of electricity based on the hours used and current tariffs. It will also allow the user to key in at least 2 items for calculation. In the future, we can include more than 2 items for calculation purposes. We also used Figma to aid with the design and development process to ensure that the user interface is intuitive and user-friendly.
# Features
The main feature of the web application are as follows:
1.	User input the device, power, hour used per day and tariff
2.	User clicks on the button
3.	The web application triggers the API to call for the update values. 
4.	The web application receives the information and display on the web page.
# Features Left to Implement
There are two feature to implement in the future as follows due to time constraints: The first is to include more than two items for calculation. The second is to display the current energy usage for this month as compare with the baseline. 
# Technologies Used
We used basic HTML,  Tailwinds and JavaScript to design and develop our basic web application.
Further to add, a couple of technologies were used as follows:
  1)	Render – Used to deploy serverless development
  2)	Postman - Used to test API endpoints before integrating into the JavaScript.
# Testing
Upon accessing the web application, the user is given with a multiple input box. The user enters values. After entering the input, the user clicks on the Calculate button. The function processes the input and updates the user interface dynamically. The user has to also enter the inputs for all the given if not the user is not allowed to click on the calculate button.
